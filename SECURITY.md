# Security Policy

## Supported versions

Security fixes are applied to the latest commit on the active release branch.
Pre-release feature branches are supported only until they are merged or
closed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include customer
data, credentials, tokens, or exploit details in public discussions. Use the
repository's **Security → Report a vulnerability** form so the maintainers can
investigate privately.

Include the affected component, reproduction steps using synthetic data,
expected impact, and any suggested mitigation. Do not test against production
systems or real customer records without explicit written authorization.

The maintainers should acknowledge a report within five business days, provide
an initial severity assessment, and coordinate disclosure after a fix is
available.
